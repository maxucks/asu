# ASU

Associative vocabulary learning — practice prototype with mock data.

## Run

```bash
bun install
bun dev
```

[http://localhost:3000](http://localhost:3000) — mock practice queue.

**Stack:** Next.js, TypeScript, Tailwind, Bun.
