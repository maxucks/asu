# Before you code

- Non-trivial change: write a **short plan** in chat or below before coding.
- User asked plan-first: **wait for alignment** before implementing.

## Plan (minimum)

1. **Intent** — one sentence.
2. **Layers** — UI | controller | repository | data source | provider.
3. **Errors** — throw below repository; `Result` + `AppError` at app layer.
4. **Files** — add/change list.
5. **Out of scope** — what this change does not do.
