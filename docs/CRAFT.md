# Craft

- **Code is a piece of art** — optimize for clarity, rhythm, and calm; every file should read well aloud.
- Prefer **one obvious way** over cleverness; delete duplication before adding abstraction.
- **Names are UI** — types and functions should tell the story without comments.
- **Small, complete units** — one responsibility per file until growth demands a split.
- **Match the room** — follow existing patterns; new code should feel native to the repo.
