# ASU

Associative vocabulary learning — **prototype**: SRS practice UI with mock data.

## Stack

- Next.js (App Router), TypeScript, Tailwind CSS
- Bun (`bun install`, `bun dev`)

## Run

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000) — practice queue from mock repository.

- Practice session only (associations + reveal + hard/medium/easy)
